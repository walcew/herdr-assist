# Sessões 2.0 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repaginar a aba Sessões para mostrar modelo, domínio da conta sem sufixo com selo corporativa/pessoal, e um medidor de contexto por agente.

**Architecture:** A ponte lê o transcript do Claude Code (por UUID) para extrair modelo e contexto% por sessão, e deriva org+corp/pessoal do e-mail da conta. Esses campos entram no payload de `agents`, e a tela de Sessões renderiza o novo layout. Degrada silencioso onde faltar dado.

**Tech Stack:** Python 3.9+ stdlib (ponte), C11 + LVGL 8.4 + cJSON (firmware), PlatformIO.

**Spec:** `docs/superpowers/specs/2026-08-20-sessoes-2-design.md`

## Global Constraints

- Ponte: só stdlib, Python 3.9. Testes rodam de dentro de `plugin/` (`cd plugin && python -m unittest ...`); `python` (Windows).
- Retrocompat: campos novos ausentes = comportamento antigo. `context_pct` ausente = 255 (desconhecido) no firmware — o 0 é valor válido.
- Segurança: do transcript, só modelo e contagem de tokens são derivados; nada de conteúdo de mensagem é lido/logado/transmitido.
- Perf: leitura de transcript cacheada por `(path, mtime)`, fora do event loop (mesmo executor do multi-conta).
- Firmware: buffers fixos — `model[16]`, `org[24]`; `context_pct` uint8 (255=desconhecido); `corp` bool.
- Build firmware: `python -m platformio run` (env `LVGL-320-480`).
- Comentários/commits em PT-BR acentuado.

- [ ] **Step 3: Implementar `transcript.py`**

```python
# plugin/transcript.py
#!/usr/bin/env python3
"""Métricas por sessão a partir do transcript do Claude Code (só stdlib).

Lê modelo e tamanho de contexto do último evento assistant. Nenhum conteúdo de
mensagem é consumido — só o id do modelo e as contagens de tokens do usage.
"""
from __future__ import annotations

import json

_NAMES = {"opus": "Opus", "sonnet": "Sonnet", "haiku": "Haiku", "fable": "Fable"}


def model_display(model_id: str) -> str:
    """`claude-opus-4-8` → `Opus 4.8`; `gpt-5` → `gpt-5`; desconhecido → id."""
    parts = (model_id or "").split("-")
    if len(parts) >= 3 and parts[0] == "claude" and parts[1] in _NAMES:
        ver = ".".join(parts[2:4]) if len(parts) >= 4 else parts[2]
        return "%s %s" % (_NAMES[parts[1]], ver)
    return (model_id or "")[:15]


def context_pct(prompt_tokens: int) -> int:
    """% da janela ocupada. Janela inferida: 1M se uso>200k, senão 200k."""
    if prompt_tokens <= 0:
        return 0
    window = 1_000_000 if prompt_tokens > 200_000 else 200_000
    return min(100, prompt_tokens * 100 // window)


def session_metrics(jsonl_path: str):
    """{"model","context_pct"} do último assistant, ou None se ilegível."""
    last = None
    try:
        with open(jsonl_path, encoding="utf-8", errors="replace") as fh:
            for line in fh:
                try:
                    o = json.loads(line)
                except ValueError:
                    continue
                msg = o.get("message")
                if isinstance(msg, dict) and msg.get("role") == "assistant":
                    last = msg
    except OSError:
        return None
    if not last:
        return None
    u = last.get("usage") or {}
    prompt = ((u.get("input_tokens") or 0) + (u.get("cache_read_input_tokens") or 0)
              + (u.get("cache_creation_input_tokens") or 0))
    return {"model": model_display(last.get("model", "")),
            "context_pct": context_pct(prompt)}
```

- [ ] **Step 4: Implementar `accounts.org_and_corp`**

Adicionar a `plugin/accounts.py`:
```python
PUBLIC_DOMAINS = {"gmail.com", "outlook.com", "hotmail.com", "live.com",
                  "yahoo.com", "yahoo.com.br", "icloud.com", "proton.me",
                  "protonmail.com", "gmx.com", "aol.com"}
_KNOWN_2LD = {"com.br", "com.mx", "co.uk", "com.ar", "com.au"}


def org_and_corp(email: str):
    """(org, corp) — org = domínio sem sufixo; corp = não é domínio público."""
    domain = (email.split("@")[-1] if email and "@" in email else "").lower()
    if not domain:
        return "", False
    corp = domain not in PUBLIC_DOMAINS
    parts = domain.split(".")
    if len(parts) >= 3 and ".".join(parts[-2:]) in _KNOWN_2LD:
        parts = parts[:-2]
    elif len(parts) >= 2:
        parts = parts[:-1]
    org = parts[-1] if parts else domain
    return org, corp
```

Perto dos caches do multi-conta, um cache de métricas por transcript:
```python
tx_cache: dict = {}   # (path, mtime) -> {"model","context_pct"}


def _session_metrics_cached(path):
    try:
        mt = os.path.getmtime(path)
    except OSError:
        return None
    key = (path, mt)
    if key not in tx_cache:
        tx_cache.clear()          # 1 sessão por pane; cache pequeno, sem crescer
        tx_cache[key] = transcript.session_metrics(path)
    return tx_cache[key]
```
(O `tx_cache.clear()` mantém no máx. um punhado de entradas; refinar se virar gargalo.)

- [ ] **Step 2: Resolver o transcript por UUID no refresh**

Em `push_agents`, ao montar cada agente `a`, quando o pane for claude e tiver
`agent_session.value` e uma conta conhecida, achar o transcript e anexar métricas.
A `pane.list` traz `agent_session` no item do pane. No laço que monta `a`:
```python
        acc = pane_account.get(pid)
        if acc:
            a["account"] = acc_email_cache.get(acc, "")

            if org:
                a["org"], a["corp"] = org, corp
        sess = (p.get("agent_session") or {}).get("value")
        if p.get("agent") == "claude" and sess and acc:
            import glob
            hits = glob.glob(os.path.join(acc[1], "projects", "*", sess + ".jsonl"))
```
